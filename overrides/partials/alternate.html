{#- Overrides Material's default language selector (globe icon + dropdown). Strategy -------- • extra.alternate must be set in both mkdocs configs — Material uses it to inject in (SEO). • Here we replace the visual widget with a single flag button whose target language is known at BUILD TIME (config.theme.language). • The flag shown is the flag of the CURRENT language (not the target), so it acts as a language indicator the user can click to switch. • data-target is read by the JavaScript in main.html at CLICK TIME (not at page-load), which fixes the navigation.instant bug where window.location changes without a reload. -#} {%- if config.extra.alternate -%} {%- if config.theme.language == 'es' -%} {%- set t_label = 'Switch to English' -%} {%- set t_lang = 'en' -%} {%- else -%} {%- set t_label = 'Cambiar a Español' -%} {%- set t_lang = 'es' -%} {%- endif -%}
{%- endif -%}
